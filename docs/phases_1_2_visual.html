Phase 1 + Phase 2

From a room full of objects to focused spatial answers.

The project builds a compact 3D scene graph, keeps only the spatial facts relevant to a question, and sends a much smaller grounded context into the answering step.

The core idea

Ask a spatial question. Retrieve only the useful slice.

Instead of handing every coordinate and label to an LLM, the pipeline narrows a room down to a small relation-aware subgraph.

01

Capture

Start with a real room reconstruction and semantic objects.

02

Extract

Turn the reconstruction into stable object records and geometry.

03

Relate

Compute typed facts such as LEFT_OF, ABOVE, and NEAR.

04

Prune

Keep only graph edges relevant to the question being asked.

05

Answer

Return grounded answers from compact context with explicit evidence.

Two-phase build

Phase 1 created the engine. Phase 2 gives it better geometry.

The distinction matters: Phase 2 improves the substrate for harder reasoning. It does not yet prove better accuracy on broader scenes.

After Phase 1 + Phase 2

What will be accomplished when both phases are complete?

The result is a reliable geometry-aware foundation. It is ready for the next phase of measured support, containment, and attachment reasoning.

1

A stable modular pipeline

Each stage can be tested or replaced independently: capture, extraction, graph building, reasoning, and evaluation.

2

Geometry-aware objects

Replica objects carry stable identities, world-frame AABBs, and oriented 3D bounding boxes instead of only centroids.

3

Structural room surfaces

The graph can preserve floors, walls, and ceilings with provenance, enabling relations that target surfaces directly.

4

Two proximity modes

The frozen Phase 1 centroid-based behavior stays comparable while Phase 2 adds an explicit surface-distance experiment.

5

Surface-relative retrieval

The system can represent candidates near the floor, wall, or ceiling through NEAR_SURFACE evidence.

6

Preserved comparability

The original Phase 1 path remains intact, so geometry experiments can be evaluated without rewriting history.

7

Better diagnostics

Checksums, geometry validators, telemetry artifacts, and graph guardrails expose drift and density changes clearly.

8

A launchpad for Phase 3

The enriched substrate supports the next extractors: ON_TOP_OF, SUPPORTS, ATTACHED_TO, and containment.

Honest interpretation

What these two phases do not prove yet.

Engineering progress and measured model improvement are different claims.

No accuracy victory lap yet

The bathroom benchmark is already saturated at 10 / 10. Harder scenes and labeled relations are needed to measure gains.

Thresholds are provisional

Phase 2 distance thresholds are Replica-calibrated defaults, not evidence of generalization to new environments.

Phase 3 remains the quality test

Support, containment, and attachment extractors still need labeled ground truth and precision / recall evaluation.
