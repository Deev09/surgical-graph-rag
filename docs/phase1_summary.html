Key contracts (Phase 1)

Identity — per-bundle, not cross-bundle
EntityIdentity.object_uid is immutable within an EntityArtifacts bundle only. Cross-bundle comparison requires an explicit BundleCorrespondence. Edges use typed GraphRef(kind="entity"|"surface", uid=...) on both sides.
empty vs unknown — externalized via CompletenessProfile
oracle source → empty when no bindings. unknown source → unknown. measured source → empty iff min(touched recall priors) ≥ empty_recall_threshold, else unknown. The executor reads ExecutionContext; extractor diagnostics stay observational.
Compat vs sparse — physically separate code paths
compat is a faithful port of relations/compute.py; the gate is byte-for-byte reproduction of the 5,414-edge legacy artifact. sparse is the desired graph: canonical-only directional, NEAR once per pair, density logical / entity ≤ 14. No shared branch logic between them.
Benchmark semantics changed (NOT a model improvement)
P1.11 fixed any_of_subset (now requires zero false positives) and added scalar count / yes_no scoring. v0.1 metrics from prior runs are NOT comparable to v0.2. See runs/p1_11_post/comparison.json for the documented delta.

Real findings recorded

Sparse defaults are Replica-calibrated

DirectionalConfig.sparse_max_distance=2.5 was chosen because room_0 (73 entities) lands at 14.52 with 3.0 — over the guardrail. 2.5 fits. Phase 3 measured precision/recall will replace this density heuristic.

Cabinet against the wall

Replica room_0 has 1 cabinet at (-0.58, 1.11, 0.34), bbox extending to x=-1.58. Has 0 LEFT_OF neighbors. Reasoner test uses NEAR(cabinet) instead (6 matches).

Identity contract verified across processes

Two oracle Replica reruns match all 73 entities via both iou_match (IoU=1.0) and shared_source_ref. Confirms object_uid + source_instance_ref survive deterministically.

"What is left of the sink?" exit demo

Replica has no sink. Under oracle context → empty ("Nothing in the scene matches that"). Under unknown context → unknown ("I don't have enough evidence..."). The decision rule works end-to-end.
