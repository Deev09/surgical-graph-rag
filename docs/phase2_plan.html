Purpose

Phase 2 builds the geometry substrate that Phase 3 support, containment, and attachment relations will rely on. Phase 1 proved that a normalized entity bundle can feed a sparse graph and a deterministic reasoner. Phase 2 enriches that bundle with world-frame oriented boxes and stable structural surfaces.

Scope Alignment
This phase enables later questions such as “what is on the chair?” and “what is near the wall?” It does not prove spatial-reasoning quality. That starts in Phase 3 when support, containment, and attachment extractors are evaluated against labeled edges.

In scope

  • World-frame oriented bounding boxes (OBBs).
  • Stable floor, wall, and ceiling surfaces.
  • Geometry validators and round-trip verification.
  • Surface-distance helpers.
  • Opt-in sparse_v2 proximity.
  • NEAR_SURFACE extraction.

Explicitly deferred

  • ON_TOP_OF, SUPPORTS, ATTACHED_TO.
  • INSIDE and CONTAINS.
  • Learned NeRF, 3DGS, OpenMask3D, LangSplat, or OpenSplat3D backends.
  • Reasoner and benchmark schema changes.

Post-Amendment Clarification

C1 · Graph-Level Surface Record

SceneGraphBundle.structural_surface_refs currently stores UIDs only. To preserve geometry and provenance without pretending surfaces are entity nodes, Phase 2 adds a dedicated graph-side SurfaceRecord.

@dataclass(frozen=True)
class SurfaceRecord:
    uid: str
    surface_type: Literal["floor", "wall", "ceiling"]
    plane: Plane
    polygon: list[Vec3] | None
    source: Literal["habitat_label", "mesh_ransac", "synth_bbox_fallback"]
    confidence: float
  • Add structural_surfaces: list[SurfaceRecord] to SceneGraphBundle.
  • Keep structural_surface_refs as a compatibility view derived from those records.
  • Round-trip the new records in P2.05 and require them for G7.
  • C1 does not block P2.01, but it must land before P2.10.

Task Plan

P2.01 — Acquire or reference raw Replica inputs

Document local paths, provenance, SHA-256 hashes, and sizes for room_0 semantic metadata and mesh inputs. Add tools/verify_replica_inputs.py.

Current status
Verifier and inventory landed. Waiting for local info_semantic.json and mesh_semantic.ply, then a one-time --init pin.
Done when: the verification tool prints hashes and sizes and exits successfully. Missing raw data must fail explicitly.

P2.02 — Extend the raw Replica importer with world-frame OBBs

Preserve Habitat orientation quaternions, derive OBB centers and half-extents, and derive tight world-frame AABBs from transformed OBB corners. Write only to scenes/replica_room_0/enriched/v2/ with schema_version: 2.

Done when: every retained entity has a populated OBB and tight derived AABB, while original Phase 1 fixture checksums remain unchanged.

P2.03 — Emit stable structural surfaces

Produce at least one floor, two walls, and one ceiling. Prefer Habitat structural labels, then mesh RANSAC. Bbox synthesis is experiment-only. Each surface has a deterministic surface_uid, provenance source, a normalized plane, and a bounded polygon when extents are available.

Done when: canonical surface identities remain stable across importer reruns, geometry validation passes, and no synth fallback enters canonical output.

P2.04 — Add geometry validators

Validate gravity, OBB extents and quaternions, normalized planes, bounded polygons, surface provenance, canonical surface sets, and deterministic hashes.

Done when: each validator has a passing case and at least one typed failure test.

P2.05 — Verify enriched serialization

Exercise existing explicit serde against enriched real oracle data, including OBB-derived AABBs and structural surfaces.

Done when: the enriched oracle bundle round-trips with array_aware_equal.

P2.06 — Surface enriched geometry through the oracle extractor

Add an opt-in enriched_path. On that path, populate entity OBBs, replace approximate AABBs, surface structural planes with provenance, and update capability flags. The default path remains Phase-1-identical.

Done when: all 73 enriched-path oracle entities carry OBBs and valid surfaces, while the default extractor bundle hash remains bit-identical to Phase 1.

P2.07 — Add surface-distance helpers

Implement pure helpers for signed point-to-plane, non-negative point-to-AABB, exact AABB-to-AABB surface gap, non-negative bbox-to-plane distance, and point-to-OBB. OBB-to-OBB distance is deferred to Phase 3.

Done when: property-style tests pass, including diagonal AABB separation where two unit cubes offset by (2,2,2) have distance sqrt(3).

P2.08 — Add opt-in sparse_v2 proximity

Extend ProximityConfig with sparse_version: Literal[1, 2] = 1. Keep sparse_v1 byte-frozen. The new v2 path uses exact AABB surface distance and is expected to emit more neighbors at the same threshold.

Done when: v1 stays bit-identical, v2 is deterministic, and per-pair distances, edge totals, and density are recorded as telemetry.

P2.09 — Add NEAR_SURFACE

Emit directional NEAR_SURFACE(entity, surface) edges with non-negative bbox-to-plane distance evidence and provisional per-surface thresholds. Skip synth fallback surfaces on the canonical path.

Done when: the frozen hand-checked smoke fixture passes with both positive and negative controls and surface proximity output is deterministic.

P2.10 — Add Phase 2 exit gates

Run the Phase 1 compat gate unchanged and add structural-surface, OBB, deterministic replay, NEAR_SURFACE, and builder-reference checks. Record sparse-v2 density as telemetry only.

Done when: blocking gates G1–G5 and G7, the full test sweeps, artifact gates, and cross-stage import check are green. G6 telemetry is recorded.
